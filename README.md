🚗 Arduino Obstacle Avoiding Car

An intelligent obstacle avoiding robot car built using Arduino UNO and Ultrasonic Sensor. The robot automatically detects nearby objects and changes direction to avoid collisions.

✨ Beginner Friendly
⚡ Easy to Build
🤖 Autonomous Navigation
🔧 Arduino Based Project

A simple Arduino UNO based obstacle avoiding robot car using:

Arduino UNO

L298N Motor Driver

HC-SR04 Ultrasonic Sensor

4 DC Motors



---

🧰 Components Required

Arduino UNO

L298N Motor Driver

HC-SR04 Ultrasonic Sensor

4 BO Motors

Robot Chassis

Wheels

Battery (7V–12V)

Jumper Wires



---

🔌 Circuit Connections

HC-SR04 Ultrasonic Sensor

HC-SR04	Arduino UNO

VCC	5V
GND	GND
TRIG	D9
ECHO	D10



---

L298N Motor Driver

L298N	Arduino UNO

IN1	D2
IN2	D3
IN3	D4
IN4	D5


ENA and ENB can remain jumpered for full speed.
